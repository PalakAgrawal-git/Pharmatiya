Launch steps

Carried out by Vaelo Creative on the day the domain moves. Half a day’s work, and the new site replaces the old one the moment it completes.

  1. Point pharmatiya.net at the new site (DNS records, provided by us)
  2. Switch the site’s addresses from the temporary preview path to the live domain
  3. Allow search engines to index the site
  4. Redirect old addresses, so existing links and search results still work
  5. Keep the old hosting running for 30 days, then cancel it

One caution: the old site stops being live the moment step 1 completes, so the date should be agreed in advance.

Not included in this phase

Listed so the boundary is clear. Any of these can be quoted separately.

  • Rebuilding the existing application at app.pharmatiya.net, including its logins, subscription tiers and usage limits
  • A blog or news section, and a system for Pharmatiya to edit pages directly
  • Ongoing content updates after launch
  • Search engine optimisation work beyond correct page titles, descriptions and redirects
  • Email newsletter platform and campaign sending
  • Analytics beyond what Vercel provides
